Rastreio desativado

Ative o rastreio com o seu contrato dos Correios

A API de rastreio dos Correios só funciona para empresas com contrato comercial, e só mostra pacotes postados nesse contrato. Sem contrato, este recurso fica desligado. A emissão das notas funciona normalmente.

  1. Um administrador gera o código de acesso no portal Correios Web Services (CWS).
  2. Cadastra o contrato e o cartão de postagem em Configurações → Integrações.
  3. O NESS testa a conexão no ambiente de homologação antes de ativar.
Configurar integração com os Correios Somente administradores podem fazer essa configuração.
